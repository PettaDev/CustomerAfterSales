# Customer flow
1. Select Infinix, TECNO or itel; enter model/build.
2. Select hardware/software and describe the reproduction.
3. Select evidence or continue without files.
4. Provide contact/country and explicit analysis consent.
5. API creates case; files are uploaded and confirmed. Keep protocol and private token.
6. Track status or add evidence at /tracking.
7. Optional PC flow: open /capture, launch the local Bridge, pair with its per-run code, connect/authorize USB, select device, approve capture, START, reproduce, STOP.
8. SPD/UNISOC: manually start YLog before recording. STOP finalizes video first, then asks for manual YLog stop before pulling logs.
9. Associate a case and its access token; opt-in automatic upload sends finalized archives. Partial evidence remains labeled partial; failed upload keeps the package and enables retry.
10. /guide retains the original PC/mobile-only fallback and translations. Its manual checklists are not automated Bridge checks. Some original instructions are MTK-specific; confirm platform before following DebugLogger steps.
